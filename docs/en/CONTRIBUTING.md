# Contribution and collaboration policy

This repository is owned by MENSTRUE. Follow [AGENTS.md](../../AGENTS.md) before editing.

- Discuss changed contracts, scientific claims and metrics with the maintainer before editing them.
- Preserve v1 model feature ordering; avoid duplicate transforms in frontend/CLI.
- Validate backend tests and frontend build, report any tests not run.
- Never add private photos, raw datasets, `.env`, `node_modules`, Python venvs, or untrusted joblib artifacts.
- Version new experiments; **do not overwrite** the current `reports/final_summary.json` as though a new run were v1.
- State exact problem, affected files, tests and limitations in any change description.
- **Commit message/push actions are managed only by the repository owner.** Do not create an arbitrary commit when contributing a local patch.
- Respect the repository's MIT code license and independent upstream dataset rights.

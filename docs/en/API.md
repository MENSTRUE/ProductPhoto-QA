# REST API contract (local MVP)

Base by default: `http://127.0.0.1:8000/api/v1`. Interactive OpenAPI docs at `http://127.0.0.1:8000/docs`.

## GET /health

Response HTTP 200 contains `status`, boolean `model_loaded`, and nullable `model_error`. Verify `model_loaded: true` before claiming learned score availability. API status `ok` alone does not prove loaded model.

## POST /analyze

`multipart/form-data` field **file** is mandatory. Accepted `image/jpeg`, `image/png`, `image/webp`, `image/bmp`; maximum upload 12 MiB. The API decodes bytes using OpenCV and rejects undecodable data. Error statuses: 400 for empty, 413 for >12 MiB, 415 for unsupported type, 422 for unreadable bytes (and standard FastAPI field validation).

Successful response schema:

```json
{
  "filename": "example.jpg",
  "status": "PASS_PROVISIONAL",
  "reasons": [],
  "metrics": {"laplacian_var": 100.0, "tenengrad": 500.0, "brightness_mean": 120.0, "brightness_std": 20.0, "dark_fraction": 0.02, "bright_fraction": 0.01, "contrast_p95_p5": 90.0, "colorfulness": 25.0, "entropy": 6.0, "width": 800.0, "height": 600.0},
  "quality_estimate": {"value": null, "scale": "1-5", "source": "KADID-10k synthetic-distortion quality regression", "available": false, "message": "example only"},
  "disclaimer": "This is a research diagnostic, not verified marketplace acceptance."
}
```

**Schema above is illustrative** and NOT a recorded prediction. A real response is generated by API. `quality_estimate.value` is number or null if unavailable. Do not use quality score as a probability, verified customer acceptance, or threshold-calibrated confidence.

PowerShell smoke tests:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/v1/health
curl.exe -X POST http://127.0.0.1:8000/api/v1/analyze -F "file=@C:\\path\\to\\photo.jpg"
```

If frontend is hosted under a different origin, configure CORS in `backend/app/core/config.py`; never use blanket wildcard origins as a substitute for reviewing production access policy.

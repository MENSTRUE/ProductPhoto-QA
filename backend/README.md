# ProductPhoto QA — Backend

## Setup (Windows PowerShell)

From the project root:

```powershell
cd backend
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs. Model file and config should exist at the repository root:
`models/kadid_quality_proxy.joblib`, `models/model_config.json`.

Endpoints: `GET /api/v1/health`, `POST /api/v1/analyze` (multipart field `file`).

**Caution**: The quality estimate is a KADID regression score, *not* merchant approval or a calibrated pass/fail classifier. The diagnostic status is heuristic.
Only load `.joblib` artifacts generated by you/trusted sources.
